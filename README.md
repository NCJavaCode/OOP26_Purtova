# OOP26_Purtova

## Опис роботи

У цій роботі я створила декілька класів на Java та попрацювала з об'єктами.

Було створено класи `Song`, `Playlist` та `User`.

У класах я використала інкапсуляцію. Поля зробила `private`, щоб до них не можна було напряму звертатися з інших класів. Для роботи з даними використовую методи класів.

### Створені класи

- `Song` — клас для створення пісень.
- `Playlist` — клас для створення плейлистів та роботи з піснями.
- `User` — клас для створення користувачів.

### Що я зробила

- створила класи;
- додала поля та методи;
- використала модифікатори доступу;
- реалізувала інкапсуляцію;
- створила об'єкти класів;
- перевірила роботу програми.

## Технології

Для виконання роботи я використовувала Java та IntelliJ IDEA.
